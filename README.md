# GC Coffee

A warm, responsive landing page and ordering experience for GC Coffee in Mambo Leo, Kisumu.

## Included

- Responsive coffee shop homepage
- GC steaming-latte inspired logo mark
- Menu cards with an interactive order basket
- Kenyan Shilling pricing
- M-Pesa checkout form for customer phone number and GC Pochi number
- Front-end validation and payment prompt confirmation state

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Before launch

The checkout currently provides a front-end confirmation only. To collect real payments, connect the form submission in `script.js` to a secure backend using an approved M-Pesa provider/API. Do not put M-Pesa credentials in browser JavaScript. Replace the placeholder phone/WhatsApp number in `index.html` with the shop's real contact details.
